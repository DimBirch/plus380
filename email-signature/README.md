# Підпис для email — THREEEIGHTY

Готовий підпис на основі логотипа **THREEEIGHTY / Epic Event Experience**.

```
email-signature/
  threeeighty-signature.html   ← сам підпис (відкрити у браузері, скопіювати, вставити)
  README.md                    ← ця інструкція
public/email/
  threeeighty-logo.png         ← картинка логотипа, яку підпис завантажує
```

---

## 1. Як поставити в Gmail

1. Відкрийте файл `threeeighty-signature.html` у браузері (подвійний клік).
2. Виділіть **усередині білої картки** — від логотипа до рядка з містом.
   Сіру підказку зверху не виділяйте, вона службова.
3. `Cmd+C`.
4. У Gmail: ⚙️ **Налаштування** → **Усі налаштування** → вкладка **Загальні** →
   прокрутіть до **Підпис** → **Створити новий** → вставте `Cmd+V`.
5. Внизу натисніть **Зберегти зміни**.

Порада: у Gmail поставте галочку «Вставляти підпис перед текстом, на який
відповідаєте» — інакше підпис буде в самому низу довгих листів.

## 2. Як поставити в Outlook

- **Outlook для Mac:** Налаштування → **Підписи** → створіть новий → вставте `Cmd+V`.
- **Outlook для Windows / вебверсія:** виділіть підпис у браузері → `Ctrl+C` →
  у редакторі підпису `Ctrl+V`. Якщо картинка не вставилась — вставте її окремо
  через **Вставити зображення → За веб-адресою** і вкажіть посилання з розділу 4.

## 3. Як поставити в Apple Mail

Mail → **Налаштування** → **Підписи** → створіть підпис → перетягніть у нього
виділений підпис із браузера. Потім **зніміть** галочку «Завжди використовувати
мій шрифт за замовчуванням», інакше Mail перемалює підпис своїм шрифтом.

---

## 4. Що змінити перед використанням

У файлі `threeeighty-signature.html` замініть три заглушки (пошуком `Cmd+F`):

| Заглушка | На що замінити |
|---|---|
| `[YOUR NAME]` | Ваше ім'я та прізвище |
| `[YOUR ROLE]` | Посада (наприклад `Founder`, `Booking Manager`) |
| `[PHONE NUMBER]` | Телефон у тому вигляді, як показувати клієнтам |

У рядку з телефоном є ще `tel:[+COUNTRYCODE PHONE]` — це посилання для кліка
з мобільного. Замініть на той самий номер **без пробелів і дужок**, наприклад
`tel:+31612345678`.

Email `hello@threeeighty.eu` і сайт `threeeighty.eu` уже вписані — це спільні
адреси компанії. Якщо у вас є особиста адреса на кшталт `ivan@threeeighty.eu`,
замініть і текст, і `href` у відповідному рядку.

### Соцмережі (необов'язково)

У файлі є закоментований блок `OPTIONAL: social links`. Розкоментуйте його
(приберіть `<!--` і `-->`) і впишіть реальні посилання, якщо потрібні.

## 5. Важливо про картинку логотипа

Підпис **не містить** картинку всередині себе — він посилається на файл, який
лежить на сайті:

```
https://threeeighty.eu/email/threeeighty-logo.png
```

Це навмисно: у такому вигляді підпис важить копійки, однаково виглядає в усіх
клієнтах і не розсилає логотип у кожному листі як вкладення.

- **Не видаляйте** файл `public/email/threeeighty-logo.png` і **не змінюйте**
  посилання — інакше логотип зникне у всіх відправлених листів.
- Якщо отримувач заблокував картинки (так роблять багато корпоративних
  поштовиків за замовчуванням), замість логотипа покажеться підпис
  `THREEEIGHTY — Epic Event Experience`. Це нормально й передбачено.
- Щоб замінити логотип, просто покладіть новий PNG під тим самим ім'ям
  `threeeighty-logo.png` і задеплойте сайт — усі підписи підхоплять його самі.

### Як перегенерувати картинку

Файл згенеровано з живого сайту, тому він точно збігається з `components/Logo.tsx`
(шрифт **Anton**, акцент `EEE` кольором `#e31b23`, підпис **JetBrains Mono**
розрідженим на `0.35em`, усе на білому тлі).

Розмір: **421×128 px**, показується як **210×64** — тобто рівно 2×, щоб бути
чітким на Retina-екранах. Якщо колись зміниться сам логотип на сайті, картинку
треба буде зробити заново тим самим способом (відрендерити логотип у браузері
й зняти скриншот елемента у 2×).
