# THREEEIGHTY — сайт промоутерської агенції

> Бренд на сайті — **THREEEIGHTY** ("Epic Event Experience"), червоно-чорно-білий. Технічна
> назва проєкту, GitHub-репозиторій і адреса `plus380.vercel.app` лишились зі старої назви —
> перейменування інфраструктури не робилося автоматично, щоб не зламати вже задеплоєне
> посилання. Якщо захочете привести їх у відповідність (або одразу підключити свій домен
> замість `plus380.vercel.app`) — скажіть, зробимо окремим кроком.

Next.js 14 (App Router) + TypeScript + Tailwind + Supabase (auth, база даних, сховище фото).
Публічний сайт — англійською, з адмін-панеллю (українською) для самостійного додавання
минулих і майбутніх подій.

## Структура проєкту

```
app/(site)/               публічний сайт (англійською, без сегмента мови в URL)
app/admin/                адмін-панель (захищена логіном, інтерфейс українською)
components/                UI-компоненти сайту
components/admin/          UI адмін-панелі (форма події, таблиця, вихід)
lib/i18n/                  тексти сайту (en.ts) і адмінки (uk.ts)
lib/supabase/               клієнти Supabase (browser + server)
lib/data/                   запити до бази подій + приклад-дані для прев'ю без бази
supabase/schema.sql          повна схема бази даних — виконати один раз у Supabase
```

Поки Supabase не підключено, сайт і адмінка все одно відкриваються — головна й
сторінка подій показують приклад-контент (`lib/data/sample-events.ts`), а вхід в
адмінку буде заблокований, доки не додасте ключі.

## 2. Підключення Supabase (база даних + логін + фото)

1. Зареєструйтесь на [supabase.com](https://supabase.com) і натисніть **New Project**.
   Оберіть назву, пароль бази даних (збережіть його) і регіон (найближчий до Європи,
   наприклад Frankfurt).
2. Коли проєкт створено — зайдіть у **SQL Editor → New query**, вставте весь вміст
   файлу [`supabase/schema.sql`](supabase/schema.sql) і натисніть **Run**. Це створить
   таблицю подій, права доступу (публічне читання, редагування тільки для вас) і
   сховище для фото `event-images`.
3. Зайдіть у **Project Settings → API**. Скопіюйте:
   - `Project URL`
   - `anon public` ключ
4. У корені проєкту скопіюйте `.env.example` у `.env.local` і вставте туди ці значення:
   ```
   NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbdc...
   ```
5. Створіть свій адмін-акаунт: **Authentication → Users → Add user** (Create new
   user), вкажіть email і пароль. Саме цими даними ви будете входити на
   `/admin/login`. (Можна додати кількох людей з команди так само.)
6. Перезапустіть `npm run dev` — на `/admin/login` тепер можна увійти, і зникне
   попередження про неналаштований Supabase.

Готово — тепер усі події, які ви додаєте через `/admin`, реально зберігаються в базі
та показуються на сайті.

## 3. Деплой на Vercel

1. Викладіть проєкт на GitHub (створіть порожній репозиторій і запуште код):
   ```bash
   git add -A
   git commit -m "Initial site"
   git branch -M main
   git remote add origin <URL_вашого_репозиторію>
   git push -u origin main
   ```
2. Зареєструйтесь / увійдіть на [vercel.com](https://vercel.com) (можна через
   GitHub-акаунт).
3. **Add New → Project**, оберіть щойно створений репозиторій.
4. У кроці **Environment Variables** додайте ті самі два значення, що й у
   `.env.local`:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
5. Натисніть **Deploy**. Через 1-2 хвилини отримаєте посилання на кшталт
   `plus380.vercel.app` — це вже робочий сайт.

Кожен наступний `git push` в `main` буде автоматично оновлювати сайт.

## 4. Домен `threeeighty.eu` (підключено ✅)

Домен куплено в GoDaddy і **вже підключено** до цього сайту — окремих дій не потрібно.
Сайт відкривається за адресою **https://threeeighty.eu**, `www.threeeighty.eu`
перенаправляє на основний домен, SSL-сертифікат видано автоматично.

Актуальні DNS-записи в GoDaddy (My Products → threeeighty.eu → DNS):

```
A      @    216.198.79.1
A      @    64.29.17.1
CNAME  www  c301971d666a55ee.vercel-dns-017.com
```

> ⚠️ **Не змінюйте записи MX і TXT.** На домені працює робоча пошта Google Workspace
> (`aspmx.l.google.com` та `alt1–4.aspmx.l.google.com`) і TXT-записи перевірки Google.
> Редагувати можна лише A та CNAME вище — інакше пошта перестане працювати.

Якщо колись знадобиться перепідключити домен: додайте його в Vercel (Settings →
Domains), потім `npx vercel domains verify threeeighty.eu` покаже точні записи, які
треба вписати в GoDaddy. Після зміни DNS оновлення зазвичай займає від 10 хвилин до
кількох годин — частина резолверів (зокрема Google DNS і домашній роутер) може тримати
стару адресу до години, і тоді браузер тимчасово показує стару сторінку-заглушку.

## 5. Як користуватись адмінкою

- Вхід: `ваш-сайт.com/admin/login`
- Додати подію: кнопка **+ Додати подію** → заповніть назву й опис (англійською —
  сайт англомовний), дату, місце, категорію, завантажте обкладинку і фото галереї →
  **Зберегти**.
- Подія автоматично потрапляє в "Майбутні" або "Минулі" на сайті — залежно від дати,
  нічого вручну перемикати не треба.
- "Показувати на головній" — вмикає подію в блоці на стартовій сторінці.
- Видалити/редагувати — іконки навпроти кожної події у списку.
